Interpretación de los indicadores

El cumplimiento institucional se calcula utilizando las programaciones semanales registradas en el formato FT-SST-147. Las actividades manuales y los cumpleaños individuales se administran de manera independiente y no modifican directamente el porcentaje institucional.

Las actividades se marcan como realizadas mediante confirmación manual. El sistema actualiza los indicadores después de registrar cada modificación.

Cuando no existen programaciones en un periodo, el cumplimiento se presenta como no aplicable.

Programaciones pendientes de clasificación

Existen 0 marcas del formato corporativo cuyo significado requiere confirmación. Estas marcas no se contabilizan como actividades realizadas mientras no se encuentren clasificadas.

Control de ejecución y trazabilidad

  • La ejecución de las actividades se confirma manualmente.
  • Las programaciones completadas conservan su fecha de realización.
  • Las modificaciones deben registrarse en el historial de auditoría.
  • Las marcas pendientes de clasificación no se contabilizan como programaciones realizadas.
  • Las programaciones canceladas permanecen identificadas dentro del seguimiento institucional.
  • Los cumpleaños individuales provenientes de Recursos Humanos no incrementan automáticamente el cumplimiento institucional.
